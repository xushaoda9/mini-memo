# Mini Memo

Mini Memo 是一个轻量的 Obsidian 快速记录插件：上方快速输入，下面按时间倒序展示历史记录，记录内容写入 Obsidian 日记文档。

## 功能

- 从左侧栏按钮或命令面板打开 Mini Memo 主工作区标签页。
- 输入内容后点击“发送”，记录会写入当天日记。
- 输入框下方的图片按钮可上传本地图片，并把图片嵌入链接插入记录。
- 默认写入 `## Mini Memo` 标题下，格式为 `- HH:mm 内容`。
- 输入内容包含 `#self` 时会被视为隐藏记录。
- 标签页左下角眼睛开关控制是否展示包含 `#self` 的记录。
- 默认读取最近 90 天记录，可在设置中修改。
- 点击左下角放大镜进入搜索模式，顶部输入区切换为搜索工具栏；支持正文与标签关键词搜索（不区分大小写），搜索覆盖所有日记记录。
- 可筛选最近 7 天、最近 30 天或自定义日期范围；结果保持时间倒序并高亮匹配文字。
- 搜索结果保留图片和引用按钮；隐藏记录仍由左下角开关控制，也不计入隐藏状态下的结果数量。
- 点击日历图标展开时间筛选；清除按钮或搜索框内 Esc 清空搜索条件。
- 点击返回箭头恢复草稿、默认历史范围和原来的滚动位置，再次进入搜索时保留搜索条件。
- 引用搜索结果会返回输入区，并将引用接到已有草稿之后，光标定位到开头。
- 默认优先跟随 Obsidian 核心 Daily notes 插件的目录和日期格式。

## 安装

1. 插件目录位于：

   ```text
   .obsidian/plugins/mini-memo/
   ```

2. 该目录中需要包含 `manifest.json`、`main.js`、`styles.css`。
3. 回到 Obsidian，刷新第三方插件列表并启用 Mini Memo。

## 日记格式

插件会在当天日记中写入类似下面的内容：

```markdown
## Mini Memo
- 22:15 今天想到一个小点子
- 22:20 ![[Attachments/photo.png]]
- 22:30 这条只想自己看 #self
```

如果你的日记已经有 `## Mini Memo` 标题，新记录会追加到该标题区域末尾；如果没有，插件会自动创建这个标题。
