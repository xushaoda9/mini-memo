# mini-memo

Mini Memo 是一个轻量的 Obsidian 快速记录插件：上方快速输入，下面按时间倒序展示历史记录，记录内容写入 Obsidian 日记文档。

## 功能

- 从左侧栏按钮或命令面板打开 Mini Memo 主工作区标签页。
- 输入内容后点击“发送”，记录会写入当天日记。
- 输入框下方的图片按钮可上传本地图片，并把图片嵌入链接插入记录。
- 默认写入 `## Mini Memo` 标题下，格式为 `- HH:mm 内容`。
- 输入内容包含 `#self` 时会被视为隐藏记录。
- 标签页左下角眼睛开关控制是否展示包含 `#self` 的记录。
- 默认读取最近 90 天记录，可在设置中修改。
- 默认优先跟随 Obsidian 核心 Daily notes 插件的目录和日期格式。

## 安装

1. 插件目录位于：

   ```text
   .obsidian/plugins/mini-memo/
   ```

## 日记格式

插件会在当天日记中写入类似下面的内容：

```markdown
## Mini Memo
- 22:15 今天想到一个小点子
- 22:20 ![[Attachments/photo.png]]
- 22:30 这条只想自己看 #self
```

如果你的日记已经有 `## Mini Memo` 标题，新记录会追加到该标题区域末尾；如果没有，插件会自动创建这个标题。
